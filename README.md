# Ubersicht-Widgets

These are a few simple widgets for Übersicht. They all support dynamic resizing and placement within the given grid and user set options, like grid size and margins.



## style.jsx

Contains global options and "style guides" to ensure a uniform look and easy setup/adjustment of some of the widgets. Make sure this file is present in your "Widgets-Folder", as all other widgets here depend on it.
